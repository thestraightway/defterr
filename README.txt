Дефтер: готовый сайт (PWA). Весь комплект статический: никаких серверов и баз данных.

Как выложить: загрузите содержимое этой папки в корень любого хостинга статических сайтов
(главное, чтобы адрес начинался с https://). Файл index.html должен лежать в корне.

Файлы:
  index.html            приложение
  legal.html            условия и конфиденциальность
  manifest.webmanifest  установка на экран «Домой»
  sw.js                 работа без интернета
  fonts/, icons/        шрифты и иконки (свои, ничего не грузится со сторонних сайтов)
  _headers              защитные заголовки (Cloudflare Pages, Netlify подхватывают сами)
