Темп: готовый сайт (PWA). Весь комплект статический: никаких серверов и баз данных.

Как выложить: загрузите содержимое этой папки в корень любого хостинга статических сайтов
(GitHub Pages, Cloudflare Pages, Netlify). Адрес должен начинаться с https://.
Файл index.html должен лежать в корне.

Как обновить: загрузите ВСЕ новые файлы поверх старых, в то же место, где лежит старый index.html
(не в отдельную папку). Приложение у клиентов обновится само: при запуске оно сверяет version.json.
Проверить: «Ещё» → «Копии и обновления» → строка «Версия от …» должна совпадать на всех телефонах.

Файлы:
  index.html            приложение
  legal.html            условия и конфиденциальность
  manifest.webmanifest  установка на экран «Домой»
  sw.js                 работа без интернета и обновления
  version.json          номер и дата текущей версии (по нему телефоны узнают об обновлении)
  icons/                иконки (свои, ничего не грузится со сторонних сайтов)
  _headers              защитные заголовки (Cloudflare Pages и Netlify подхватывают сами)
